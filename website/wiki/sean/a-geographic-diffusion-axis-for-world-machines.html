A geographic-diffusion axis for the World Machines periodization

Sean · updated 13 September 2026 · source on GitHub
The World Machines framework tracks which operative logic a moment runs on and how fast its registers change once it's operating, but has no explicit axis for how unevenly a machine spreads geographically once it exists somewhere — a machine can originate in one place and take centuries to actually finish arriving in another.

The idea

The World Machines framework periodizes history by which operative logic of coordination and meaning — which "machine" — a given moment runs on, and existing discussions track how fast a given register inside that machine changes, on Stewart Brand's pace-layer model: fashion fast, commerce faster than infrastructure, infrastructure faster than governance and culture. What's missing is an explicit axis for a different kind of unevenness: how long it actually takes a machine to spread geographically once it exists anywhere at all.

The modernity machine is usually dated to a fairly specific origin point, but full deployment in a given place can lag that origin by centuries — one account of Egypt's modernization holds that full deployment didn't complete there until after World War II, well after the modernity machine's canonical starting point elsewhere. That's a different kind of variability from pace-layer speed. Pace layers describe how fast a register changes once a machine is already operating in a place; geographic diffusion describes how long it takes the machine to finish arriving somewhere at all. Naming this as its own axis would let the framework distinguish "this place hasn't started running on the new machine yet" from "this place is running on it, but its slow layers haven't caught up" — two situations that are currently easy to conflate under a single story about a machine's arrival.

Grounding

Original proposal, extending Rao's World Machines framework and Stewart Brand's pace-layer model. The Egypt example is drawn from a secondhand reference (a Substack article on Egyptian modernization) rather than checked directly against primary economic-history sources.

How settled this is

This is a proposed addition to the framework, not yet checked against Rao's own writing on World Machines or tested against a wider set of cases beyond the single Egypt example. Whether geographic diffusion speed is genuinely a separate axis, rather than simply an instance of an existing register being slow in a particular place, is itself worth pressure-testing before treating it as established.

Open

Does geographic diffusion lag turn out to be genuinely independent of pace-layer speed once examined closely, or does it collapse into "the governance and culture layers in that particular place were already slow" — the same phenomenon under a different name?
