Frameworks can turn performative as they become more sophisticated

Florian · updated 14 September 2026 · source on GitHub
Sophisticated frameworks can quietly replicate the same passive deferral structure they claim to help you escape, and the pattern — any evidence confirms the thesis — migrates across intellectual traditions regardless of how sophisticated the surface reasoning gets.

The idea

A framework can become unfalsifiable in the exact same way regardless of how intellectually sophisticated it is on the surface — and the pattern is a deferral structure: something else, some larger machine, becomes the standing explanation for whatever happens, so that no observation can ever actually count against the framework. Sophistication doesn't protect against this. If anything, it makes the deferral harder to spot, because a sophisticated deferral looks like an argument instead of an excuse.

Three instances carry the pattern, in ascending order of how close to home the last one gets. Leibniz's theodicy defers everything to God's plan — this is the best of all possible worlds, so any apparent evil is, by definition, part of a larger good you can't see. Contemporary tech optimism defers to Progress's trajectory — any present harm is a temporary cost on the way to an inevitable better future, so no present harm can actually count as evidence against the trajectory. And — this is the point that gives the note its edge — the divergence thesis itself is a candidate third instance: any present dysfunction can be "explained" by where we sit in the periodization, always mid-transition, always between machines. That's structurally the same move as the first two.

The sting is self-reflexive on purpose. The World Machines framework diagnoses this deferral pattern in other traditions and has to reckon with the possibility that it exhibits the same structure it diagnoses. When a theory can't be falsified by any evidence — when every counterexample gets absorbed as "that's just the old machine's residue" or "that's just mid-transition" — it may itself be functioning as what the decay-sequence cluster calls a performative moat: a structure that no longer does the explanatory work it claims to, and instead exists to be defended.

This is held deliberately as a live tension with the decay-sequence cluster rather than resolved into it. The two claims pull against each other — one says frameworks decay into performance, the other worries the very act of naming that decay might itself already be performing it — and reconciling them prematurely would be exactly the kind of false closure this note is warning against.

Where it comes from

Developed across The Best of All Possible Worlds (Notefields, January 2026) and the postscript to Shitty Castles (Notefields, March 2026), where the self-reflexive version of the claim — that the divergence thesis might exhibit its own diagnosed pattern — gets stated explicitly.

How settled this is

The Leibniz and Progress-optimism cases are well-established readings, not original to me. The self-reflexive extension — that the World Machines framework itself might be a third instance — is mine, and it's the part I take most seriously precisely because I have the least distance from it. I don't currently have a way to tell, from inside the framework, whether this note is a genuine safeguard against that failure mode or just another sophisticated-looking layer of the same deferral. That uncertainty is the actual content of the note, not a hedge around it.

Open

Is there an honest way to hold the "advantageous vs. true" gap open — acknowledging that a framework might be performing a function without pretending that function makes it true? I don't have a resolved answer; Marking the gap is more insightful than forcing closure is the closest candidate, and even that one is explicitly in tension with this note rather than settling it.
