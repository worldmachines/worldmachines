A possibility closed upstream leaves no trace that it was ever a possibility

Florian · updated 14 September 2026 · source on GitHub
A prohibited option is perceived as missing and can be argued about; an option resolved upstream never appears as an option at all, so foreclosure done early enough leaves no evidence of itself — which makes invisibility, not speed, the political difficulty of Micro Time.

The idea

A prohibition announces itself. Something is greyed out, refused, denied, rate-limited, unavailable in your region — and being perceptible, it is arguable. You can name it, object to it, organise about it, find out who decided. Refusal generates its own evidence.

Foreclosure done far enough upstream generates none. If a system filters, ranks, routes or resolves before the interface renders, the alternatives that lost do not appear as losses. They do not appear at all. From inside the surviving field of options, nothing looks crossed out — the field simply is what it is, and there is no perceptual difference between a situation that was always this narrow and one that was narrowed a few hundred microseconds ago by something you will never see. This is the actual political difficulty of Micro Time, and it is not speed. Speed is only how the closure got upstream of perception.

The consequence for analysis is specific and it changes what you go looking at. The standard question about a system is what it lets a user choose, and that question is answered at the interface, which is exactly the layer this problem defeats. The better question is what was already sensed, filtered, ranked, inferred or resolved before the interface appeared. Increasingly the interface is not where the decision is made; it is where the result is shown, and studying it carefully tells you about the display.

The same structure shows up in a softer register with generative models. A person starts with a half-formed thought and the model supplies continuations, categories and formulations before the thought has finished forming. It need not determine the final thought to shape the field it emerges from: some paths become cheap, fluent and already articulated, others stay invisible or cost more to reach. Nobody is prevented from thinking anything. The distribution of effort across the possibility space has been quietly reshaped, leaving the same kind of no-trace the infrastructural version does.

This costs the claim something, and I want to be honest about it. A thesis whose central object is by construction unobservable is in a bad evidential position, structurally close to the deferral pattern I distrust elsewhere — any absence of evidence reads as confirmation. The escape, if there is one, is not to argue from the missing possibilities but to work on the systems: logging, observability, provenance, audit, the ordinary institutional expertise that reopens a lower layer. Opacity is not total. It is expensive to penetrate, which is a different, tractable problem.

Where it comes from

From "Time Moves Down the Stack" (Protocol Institute Symposium, 2026), from the futures-cone section and the treatment of large language models as a cognitive instance of upstream narrowing. Sachin Benny's phrase for the latter is the pre-commodification of ideas. The talk turns this on itself too: an oracle ingesting a symposium's material can preserve its possibility field or make a few framings disproportionately available — the same mechanism operating on the argument that describes it.

How settled this is

The mechanism is solid: systems demonstrably filter, rank and resolve before rendering, and this is a description of how they are built, not an interpretation of what they are up to.

That meaningful possibilities are being consumed this way, at scale, is an inference from the mechanism, not an observation, for the reason just given. I hold it as a strong structural expectation rather than a finding. The honest test is indirect: in systems where observability was later built in — logs, audit trails, disclosed ranking criteria — did anything turn up nobody at the interface had suspected? If reopened layers consistently hold no surprises, the mechanism exists but isn't doing the work I'm attributing to it.

Open

What would count as a positive instance? I need one documented case where a foreclosed alternative was recovered after the fact — a leak, an audit, a disclosure — and shown to have been live before the system resolved it. I don't have one, and I'm not sure whether that's because they're rare or because I haven't known where to look.
